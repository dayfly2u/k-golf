# 워치 UX2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 워치 앱(`wear`)을 확정 시안(WatchIdle / WatchPlay / WatchHole)의 원형 UI로 교체하고, 폰이 워치에 "합계"와 "이전 홀 결과"를 보내도록 통신을 확장한다.

**Architecture:** 폰 `RoundRecordingService.pushState`가 샷·벌타 기록에서 `scoreBefore`와 이전 홀 결과를 계산해(순수 함수 + 단위 테스트) 새 DataMap 키로 보낸다. 워치는 `RoundUiState`에 두 값을 더 읽고, `MainActivity`가 상태에 따라 대기/홀 기록/홀 이동 화면 중 하나를 그린다. 화면 로직(등급 이름, 합계, 링 칸, 연결 배지, 홀 이동 타이머)은 Android 의존 없는 순수 코드로 분리해 JVM 테스트한다. 통신·낙관적 표시·GPS 로직은 건드리지 않는다.

**Tech Stack:** Kotlin, Jetpack Compose + `androidx.wear.compose` 1.4.1(material/foundation), Play Services Wearable Data Layer, JUnit4, kotlinx-coroutines-test.

- **홀별 타수는 `hole_records`가 아니라 샷·벌타 기록에서** 구한다: 홀별 `StrokeCalculator.currentTotal`(`TO_GREEN` + `SHORT_GAME` + `PUTT`, 벌타 포함). 파는 코스 홀의 파, 코스에 없는 홀 번호는 4. `scoreBefore`는 현재 홀보다 번호가 작은 홀 중 **타수가 1 이상인 홀**만 (타수 − 파)를 더한다.
- **색(시안 그대로):** 배경 `#000000`, 어두운 버튼 `#1E2A22`, 링 남은 칸 `#26332B`, 강조 녹색 `#2E7D4F`, 노랑 `#F2C14E`, 회색 라벨 `#9AA59C`, 연결 점 `#4CAF50`, 호박 알약 배경 `#3A2A0E`, 대기 본문 `#C9D1CB`, 대기 힌트 `#7E8A82`, 흰색 `#FFFFFF`.
- **등급 이름:** `-3 앨버트로스, -2 이글, -1 버디, 0 파, 1 보기, 2 더블, 3 트리플`, 그 밖은 부호 숫자(`+4`, `-4`). 이 홀 타수가 0이면 등급은 `-`.
- **합계 표기:** 양수 `+5`, 0은 `0`, 음수 `-2` (폰의 "E"와 다름). 합계 = `scoreBefore + (이 홀 타수 > 0 ? 이 홀 타수 − 파 : 0)`.
- **글꼴:** 숫자(타수·홀 번호·합계)만 Barlow Condensed(`res/font/barlow_condensed_{medium,semibold,bold}.ttf`, 폰 앱 `app/src/main/res/font/`에서 복사). 한글은 시스템 글꼴.
- **링:** 홀 수만큼 칸, 12시 방향에서 시계 방향으로 시작, 지나온 홀=강조 녹색 / 현재 홀=노랑 / 남은 홀=`#26332B`. 시안 기준 반지름 170, 두께 7, 칸 사이 틈 4(모두 360 기준 단위).
- **화면 배율:** `factor = min(폭, 높이) / 360`을 도형·간격·위치에 곱하되, 글자는 역할별 최소 sp(기본 10), 원형 버튼은 최소 dp(스테퍼 38, 이전/다음 홀 34, 홀 이동 화면 40)를 둔다. 대상 워치는 198×198dp(factor 0.55).
- **홀 이동 화면:** 워치에서 ◀/▶를 눌러 홀이 바뀐 경우에만 뜬다. 표시 2.5초(`HOLE_SCREEN_MS = 2500L`), 이동 요청 유효 5초(`MOVE_REQUEST_TIMEOUT_MS = 5000L`), 탭하면 즉시 닫힘, 표시 중 홀이 또 바뀌면 타이머 재시작. 이전 홀 기록이 없으면 하단 첫 줄 생략.
- **기존 동작 유지:** 타수 ±(`그린까지`/`숏 · 퍼팅`), 값 0에서 − 비활성, 1홀에서 ◀ 비활성·마지막 홀에서 ▶ 비활성, GPS 실패 시 진동 200ms + "GPS 신호 없음" 2.5초, 위치 권한 요청, `WatchLocationService` 시작/정지. 기존 "재연결" 2.5초 문구는 없앤다.

```kotlin
        val result = calculate(1, holeShots(1, toGreen = 2))
        assertEquals(0, result.scoreBefore)
        assertNull(result.previousHole)
    }

    @Test
    fun `sums score to par of earlier holes and reports the previous hole`() {
        // 1번 홀: 2+2 = 4타(파 4 → 0), 2번 홀: 3+1+2 = 6타(파 5 → +1)
```

```kotlin
package com.golfrecorder.domain.model

import com.golfrecorder.data.local.entity.PenaltyEntity
import com.golfrecorder.data.local.entity.ShotEntity

/** 워치 "홀 이동" 화면의 "{n}번 홀 {타수}타 · {등급}" 줄에 쓰는 이전 홀 결과. */
data class PreviousHoleResult(val strokes: Int, val par: Int)

/** 폰이 워치로 보내는 합계 기준값과 이전 홀 결과. */
data class WatchRoundSummary(
    /** 현재 홀보다 번호가 작은 홀 중 타수가 1 이상인 홀의 (타수 − 파) 합. 해당 홀이 없으면 0. */
    val scoreBefore: Int,
    /** 바로 이전 홀(현재 번호 − 1)의 결과. 1번 홀이거나 그 홀 타수가 0이면 null. */
    val previousHole: PreviousHoleResult?,
)

object WatchRoundSummaryCalculator {
    private const val DEFAULT_PAR = 4
    private val PHASES = listOf(ShotPhase.TO_GREEN, ShotPhase.SHORT_GAME, ShotPhase.PUTT)

    /**
     * 홀별 타수는 hole_records가 아니라 샷·벌타 기록에서 구한다 — hole_records는 폰 라운드
     * 화면이 열려 있을 때만 저장되는데, 워치로만 기록하는 동안에는 RoundRecordingService만
     * 살아 있기 때문이다. 워치 화면에 이미 보이는 타수(그린까지 + 숏/퍼팅, 벌타 포함)와
     * 같은 기준이다.
     */
    fun calculate(
        currentHoleNumber: Int,
        parByHole: Map<Int, Int>,
        shots: List<ShotEntity>,
        penalties: List<PenaltyEntity>,
    ): WatchRoundSummary {
        val shotsByHole = shots.groupBy { it.holeNumber }
        val penaltiesByHole = penalties.groupBy { it.holeNumber }

        fun strokesOf(hole: Int): Int {
            val holeShots = shotsByHole[hole].orEmpty()
            val holePenalties = penaltiesByHole[hole].orEmpty()
            return PHASES.sumOf { phase -> StrokeCalculator.currentTotal(holeShots, holePenalties, phase) }
        }

        fun parOf(hole: Int): Int = parByHole[hole] ?: DEFAULT_PAR

        var scoreBefore = 0
        for (hole in 1 until currentHoleNumber) {
            val strokes = strokesOf(hole)
            if (strokes > 0) scoreBefore += strokes - parOf(hole)
        }

        val previousHole = (currentHoleNumber - 1).takeIf { it >= 1 }?.let { hole ->
            val strokes = strokesOf(hole)
            if (strokes > 0) PreviousHoleResult(strokes, parOf(hole)) else null
        }
        return WatchRoundSummary(scoreBefore, previousHole)
    }
}
```

```kotlin
package com.golfrecorder.wear

import androidx.compose.runtime.Immutable
import androidx.compose.ui.unit.Dp
import androidx.compose.ui.unit.TextUnit
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp

/**
 * 시안은 360×360 기준이다. 실제 워치(예: 198dp)에서는 배율이 0.55 안팎이라 시안의 글자·
 * 버튼을 그대로 곱하면 11px 라벨이 6sp, 52px 버튼이 29dp가 되어 읽거나 누를 수 없다.
 * 그래서 도형·간격·위치는 비례로 두고, 글자와 눌러야 하는 버튼에는 하한을 둔다.
 */
@Immutable
class WatchScale private constructor(private val factor: Float) {

    /** 도형·간격·위치 — 시안 px을 비례로만 변환. */
    fun dp(designPx: Float): Dp = (designPx * factor).dp

    /** 글자 — 비례하되 [minSp] 아래로는 내려가지 않는다. */
    fun sp(designPx: Float, minSp: Float = MIN_TEXT_SP): TextUnit = maxOf(designPx * factor, minSp).sp

    /** 눌러야 하는 원형 버튼 지름 — 비례하되 [minDp] 아래로는 내려가지 않는다. */
    fun touch(designPx: Float, minDp: Float = MIN_TOUCH_DP): Dp = maxOf(designPx * factor, minDp).dp

    companion object {
        const val DESIGN_SIZE = 360f
        const val MIN_TEXT_SP = 10f
        const val MIN_TOUCH_DP = 38f

        fun forScreen(minSide: Dp): WatchScale = WatchScale(minSide.value / DESIGN_SIZE)
    }
}
```

```kotlin
/** 이 홀 결과 이름 — 시안(WatchPlay.dc.html)의 names 표와 같다. 표에 없는 값은 부호 숫자. */
fun holeGradeName(scoreToPar: Int): String = when (scoreToPar) {
    -3 -> "앨버트로스"
    -2 -> "이글"
    -1 -> "버디"
    0 -> "파"
    1 -> "보기"
    2 -> "더블"
    3 -> "트리플"
    else -> formatTotal(scoreToPar)
}

/** 합계 표기: 양수 `+5`, 0은 `0`, 음수 `-2` (폰의 "E"와 다름 — 시안 로직). */
fun formatTotal(scoreToPar: Int): String = if (scoreToPar > 0) "+$scoreToPar" else "$scoreToPar"

/** "이 홀 {strokes}타 · {gradeName}" 줄. 타수가 0이면 등급은 "-". */
data class HoleSummary(val strokes: Int, val gradeName: String)

fun holeSummary(strokes: Int, par: Int): HoleSummary =
    HoleSummary(strokes, if (strokes > 0) holeGradeName(strokes - par) else "-")

/** 합계 = 현재 홀 이전까지의 파 대비 합 + (이 홀을 치기 시작했으면 이 홀의 파 대비). */
fun runningTotal(scoreBefore: Int, holeStrokes: Int, par: Int): Int =
    scoreBefore + if (holeStrokes > 0) holeStrokes - par else 0

enum class RingSegment { DONE, CURRENT, REMAINING }

/** 진행 링의 칸 상태 — 홀 번호 1..[holeCount] 순서. */
fun ringSegments(holeCount: Int, currentHole: Int): List<RingSegment> =
    List(holeCount.coerceAtLeast(0)) { index ->
        val hole = index + 1
        when {
            hole < currentHole -> RingSegment.DONE
            hole == currentHole -> RingSegment.CURRENT
            else -> RingSegment.REMAINING
        }
    }

enum class StatusBadge { CONNECTED, DISCONNECTED, GPS_FAILURE }

/** 맨 위 상태 줄에 무엇을 보일지 — 잠깐 뜨는 GPS 실패가 가장 우선, 그다음 연결 끊김. */
fun statusBadge(isPhoneConnected: Boolean, showGpsFailure: Boolean): StatusBadge = when {
    showGpsFailure -> StatusBadge.GPS_FAILURE
    !isPhoneConnected -> StatusBadge.DISCONNECTED
    else -> StatusBadge.CONNECTED
}
```

```kotlin
package com.golfrecorder.wear

import androidx.compose.foundation.Canvas
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.geometry.Offset
import androidx.compose.ui.geometry.Size
import androidx.compose.ui.graphics.StrokeCap
import androidx.compose.ui.graphics.drawscope.Stroke

// 시안(WatchPlay.dc.html)의 SVG 링: 360 기준 반지름 170, 두께 7, 칸 사이 틈 4(원둘레 방향 길이).
private const val RING_RADIUS = 170f
private const val RING_STROKE = 7f
private const val RING_GAP = 4f

/** 화면 가장자리를 따라 홀 수만큼 칸을 그린다. 12시 방향에서 시계 방향으로 시작. */
@Composable
fun WatchRing(segments: List<RingSegment>, modifier: Modifier = Modifier) {
    Canvas(modifier) {
        if (segments.isEmpty()) return@Canvas
        val unit = size.minDimension / WatchScale.DESIGN_SIZE
        val radius = RING_RADIUS * unit
        val center = Offset(size.width / 2f, size.height / 2f)
        val step = 360f / segments.size
        val gapDegrees = (RING_GAP / (2f * Math.PI.toFloat() * RING_RADIUS)) * 360f
        segments.forEachIndexed { index, segment ->
            drawArc(
                color = when (segment) {
                    RingSegment.DONE -> WatchColors.Accent
                    RingSegment.CURRENT -> WatchColors.Yellow
                    RingSegment.REMAINING -> WatchColors.RingRemaining
                },
                startAngle = -90f + index * step,
                sweepAngle = step - gapDegrees,
                useCenter = false,
                topLeft = Offset(center.x - radius, center.y - radius),
                size = Size(radius * 2f, radius * 2f),
                style = Stroke(width = RING_STROKE * unit, cap = StrokeCap.Butt),
            )
        }
    }
}
```

```kotlin
package com.golfrecorder.wear

import androidx.compose.runtime.Composable
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.Stable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import kotlinx.coroutines.delay

private const val HOLE_SCREEN_MS = 2500L
private const val MOVE_REQUEST_TIMEOUT_MS = 5000L

/**
 * "홀 이동" 화면을 언제 띄울지 — 워치에서 ◀/▶를 눌러 홀이 바뀐 경우에만 뜬다(폰에서 바뀐
 * 경우는 조용히 홀 기록 화면만 갱신). 누르면 [request]로 "이동 요청"이 서고, 폰이 처리해서
 * 홀 번호가 실제로 바뀌면([onHoleChanged]) 화면을 2.5초 보여준다. 폰과 연결이 끊겨 홀이 안
 * 바뀌는 경우를 위해 요청은 5초 뒤 만료된다([expireRequestAfterTimeout]).
 */
@Stable
class HoleMoveOverlayState {
    var pending by mutableStateOf<HoleMoveDirection?>(null)
        private set
    var shownDirection by mutableStateOf<HoleMoveDirection?>(null)
        private set

    fun request(direction: HoleMoveDirection) {
        pending = direction
    }

    fun dismiss() {
        shownDirection = null
    }

    suspend fun expireRequestAfterTimeout() {
        if (pending != null) {
            delay(MOVE_REQUEST_TIMEOUT_MS)
            pending = null
        }
    }

    /**
     * 홀 번호가 바뀔 때마다 호출한다. 이동 요청이 있으면 그 방향으로 화면을 띄우고, 이미
     * 떠 있는 중(연속 이동 포함)이면 방향은 그대로 두고 타이머만 처음부터 다시 센다.
     * 호출한 코루틴이 홀 번호 키 변경으로 취소돼도 다음 호출이 타이머를 이어받으므로
     * 화면이 끝없이 떠 있지 않는다.
     */
    suspend fun onHoleChanged() {
        pending?.let { requested ->
            shownDirection = requested
            pending = null
        }
        if (shownDirection != null) {
            delay(HOLE_SCREEN_MS)
            shownDirection = null
        }
    }
}

@Composable
fun rememberHoleMoveOverlay(holeNumber: Int): HoleMoveOverlayState {
    val overlay = remember { HoleMoveOverlayState() }
    LaunchedEffect(overlay.pending) { overlay.expireRequestAfterTimeout() }
    LaunchedEffect(holeNumber) { overlay.onHoleChanged() }
    return overlay
}
```

```kotlin
private fun vibrateFailure(context: Context) {
    val vibrator = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
        (context.getSystemService(Context.VIBRATOR_MANAGER_SERVICE) as VibratorManager).defaultVibrator

@Composable
fun RoundControlScreen(viewModel: RoundStateViewModel) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    val isPhoneConnected by viewModel.isPhoneConnected.collectAsStateWithLifecycle()
    val context = LocalContext.current

    // 폰 화면의 "위치를 가져오지 못해 기록되지 않았습니다" Toast와 같은 의도 — 워치는
    // 화면이 작아 텍스트 대신 진동 + 잠깐 뜨는 안내 문구로 알려준다. 처음 값을 받을
    // 때는(baseline) 반응하지 않고, 그 뒤에 값이 갱신될 때만(=새로운 실패) 반응한다.
    var lastSeenFailedAt by remember { mutableStateOf<Long?>(null) }
    var showGpsFailureMessage by remember { mutableStateOf(false) }
    LaunchedEffect(state.lastFailedAt) {
        val seen = lastSeenFailedAt
        if (seen != null && state.lastFailedAt > seen) {
            vibrateFailure(context)
            showGpsFailureMessage = true
            delay(GPS_FAILURE_MESSAGE_MS)
            showGpsFailureMessage = false
        }
        lastSeenFailedAt = state.lastFailedAt
    }

    // 이 라운드가 "워치 기준"일 때만 워치 자체 GPS가 필요하다 — 앱을 열 때마다
    // 무조건 권한을 묻지 않고, 실제로 필요한 순간(워치 기준 라운드 진행 중)에만
    // 묻는다.
    var hasLocationPermission by remember {
        mutableStateOf(
            ContextCompat.checkSelfPermission(context, Manifest.permission.ACCESS_FINE_LOCATION) ==
                PackageManager.PERMISSION_GRANTED,
        )
    }
    val locationPermissionLauncher = rememberLauncherForActivityResult(
        ActivityResultContracts.RequestPermission(),
    ) { granted -> hasLocationPermission = granted }

    LaunchedEffect(state.roundActive, state.useWatchLocation, hasLocationPermission) {
        if (state.roundActive && state.useWatchLocation && !hasLocationPermission) {
            locationPermissionLauncher.launch(Manifest.permission.ACCESS_FINE_LOCATION)
        }
    }

    // 폰의 RoundPlayScreen이 RoundRecordingService를 시작/정지하는 것과 같은 모양 —
    // 라운드가 살아있고 워치 기준이며 권한이 있을 때만 포그라운드 GPS 서비스를 띄운다.
    LaunchedEffect(state.roundActive, state.useWatchLocation, hasLocationPermission) {
        if (state.roundActive && state.useWatchLocation && hasLocationPermission) {
            WatchLocationService.start(context)
        } else {
            WatchLocationService.stop(context)
        }
    }

    // ◀/▶를 누르면 홀 이동 요청을 세우고 액션을 보낸다 — 폰이 처리해서 홀 번호가 실제로
    // 바뀌면 홀 이동 화면이 잠깐 뜬다(HoleMoveOverlayState 참고).
    val overlay = rememberHoleMoveOverlay(state.holeNumber)
    val onMove: (HoleMoveDirection) -> Unit = { direction ->
        overlay.request(direction)
        viewModel.sendAction(
            if (direction == HoleMoveDirection.NEXT) WearSync.ACTION_NEXT_HOLE else WearSync.ACTION_PREV_HOLE,
        )
    }

    val shownDirection = overlay.shownDirection
    when {
        !state.roundActive -> WatchIdleScreen(isPhoneConnected = isPhoneConnected)
        shownDirection != null -> WatchHoleScreen(
            state = state,
            direction = shownDirection,
            onMove = onMove,
            onDismiss = overlay::dismiss,
        )
        else -> WatchPlayScreen(
            state = state,
            badge = statusBadge(isPhoneConnected, showGpsFailureMessage),
            onAction = viewModel::sendAction,
            onMove = onMove,
        )
    }
}
```

3. **화면 확인은 사용자 몫** — 설치 뒤 "무엇을 눌러 무엇을 봐 달라"를 구체적으로 안내: (a) 라운드 없을 때 대기 화면, (b) 라운드 시작 후 홀 기록 화면의 글자·버튼 크기와 잘림 여부(특히 맨 위 상태 줄, 맨 아래 두 줄, 이전/다음 홀 줄), (c) ▶ 눌렀을 때 홀 이동 화면과 이전 홀 결과/합계, (d) 탭하면 닫히는지·2.5초 뒤 자동으로 닫히는지, (e) 폰에서 홀을 바꿀 때는 이동 화면이 안 뜨는지. 크기 하한(`WatchScale`, 화면 파일 상단 상수)은 이 확인 결과로 조정한다.
4. 마무리 후 `claude plugin disable superpowers@superpowers-marketplace`.
