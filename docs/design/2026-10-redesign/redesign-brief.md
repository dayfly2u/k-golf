## 0. 진행 원칙

1. **디자인 교체와 신규 기능을 분리한다.** 1단계는 기존 기능 그대로 보기만 바꾸고, 신규 기능은 그 뒤에 기능별로 하나씩 추가한다.
2. **DB 마이그레이션 규칙(CLAUDE.md) 준수.** 스키마가 바뀌는 항목은 명시적 `Migration`을 쓰고, 실기기 업그레이드로 기존 라운딩 기록 보존을 확인한다.
3. 아키텍처 컨벤션 유지: 수동 `AppContainer` DI, `sealed interface Screen` 백스택, 화면 단위 ViewModel+Composable 한 파일.
4. 각 단계가 끝날 때마다 실기기에 설치해 확인한다.

## 2. 화면별 정리: 기존 기능 vs 신규 기능

표기: **[기존]** 지금 앱에 있음(디자인만 교체) · **[신규-UI]** 기존 데이터로 계산/표시만 추가 · **[신규-데이터]** 저장 구조나 새 로직 필요

### 2.1 홈 (Main.dc.html) — `RoundHistoryScreen`
- [기존] 라운드 리스트: 코스명, 라운딩 시간 `MM.dd (요일) HH:mm~HH:mm (N시간 M분)`, 스코어 뱃지
- [기존] 카드 탭 → 펼침: 그린피·동반자, 라운딩 리뷰, GIR/퍼팅/드라이버 통계, 상세 결과 이동
- [기존] 리뷰 없을 때 안내 → 디자인에서는 "리뷰 남기기" 링크
- [신규-UI] 상단 요약: 평균 스코어, 베스트, 평균 퍼팅 (전체 라운드 기준)
- [신규-UI] 스코어 뱃지에 파 대비(+22) 표시
- 변경: "새 라운딩 시작!"을 하단 고정 큰 버튼으로, "코스 관리"는 상단 우측 버튼
- 확인 필요: 스코어 뱃지 색 기준. 지금은 80대/90~94/95~99/100+ 구간색, 시안은 베스트/양호/보통 3단계 예시. 현재 구간 기준 유지가 기본안.

### 2.2 홀 기록 (RoundPlay.dc.html) — `RoundPlayScreen` (라이브)
- [기존] 홀 번호·파, 지도, 위치 조정, 그린까지/숏게임/퍼팅 스테퍼, OB +1/+2, 해저드 +1, 이전/다음 홀
- [신규-UI] 18홀 진행 바 (완료 홀/현재 홀/남은 홀)
- [신규-UI] 상단 "현재 스코어" (진행 홀까지 파 대비)
- [신규-UI] 다음 홀 버튼에 이 홀 타수 요약 ("이 홀 5타 · 보기")
- [신규-UI] 지도 위 "그린 중앙까지 142m" 오버레이. 그린 좌표와 현재 위치는 이미 있음(지금은 오프라인일 때만 텍스트로 표시).

### 2.3 라운드 결과 (Summary.dc.html) — `RoundSummaryScreen`
- [기존] 코스명, 라운딩 시간, 총타수, 18홀 스코어카드, 홀 탭 → 홀 상세, 리뷰 작성, 삭제
- [기존] GIR 계산 2종. **이름 변경**: 지금의 "엄격 GIR" → **GIR**, 지금의 "GIR"(숏어프로치 있어도 인정) → **L-GIR**
- [기존] 드라이버 평균/최장 (`DriverDistanceStats`), 퍼팅 합계·홀당 평균, 벌타(OB/해저드)
- [신규-UI] 통계 6칸 그리드: GIR, L-GIR, 퍼팅, 드라이버 평균, 드라이버 최장, 벌타
- [신규-UI] 홀 결과 비율: 버디 이하/파/보기/더블/트리플+ 를 **하나의 100% 막대**에 퍼센트로, 아래 범례에 홀 수
- [신규-UI] "최근 5회 중 N위" 뱃지
- [신규-데이터] "스코어카드 공유" 버튼 (이미지 생성 + 공유 인텐트) — 별도 단계로 미뤄도 됨
- 변경: 스코어카드 타수 칸을 누르면 바로 홀 상세. "홀 경로 보기" 버튼은 없음.

### 2.4 홀 상세 (Hole.dc.html) — `RoundPlayScreen` isReview 모드
- [기존] 지도 위 샷 경로와 샷 사이 거리(직선, 고저차 미반영), 결과만 표시(수정 불가)
- 변경: 홀 기록 화면과 같은 틀(헤더, 18홀 진행 바, 지도, 타수 행, 벌타, 이전/다음 홀). 스테퍼 버튼 없이 숫자만. 벌타는 "OB 0 · 해저드 0" 칩. 샷별 거리 목록은 넣지 않음(지도와 중복).
- 헤더 우측에 이 홀 결과("7 · 더블")

### 2.5 코스 관리 (CourseManage.dc.html) — `CourseManageScreen`
- [기존] 드래그 순서 변경(≡), 코스명, 평점, 난이도, 지역·거리·시간, 한줄평, 펼치면 교통/클럽하우스/코스 리뷰 + 유튜브 링크, 수정 버튼
- 변경: 평점은 노란 별 + 숫자, 난이도는 주황 칩 "난이도 3.5" (지금은 둘 다 ★라 헷갈림)
- 변경: "새 코스 추가"를 하단 고정 큰 버튼으로

### 2.6 코스 추가·수정 (CourseEdit.dc.html) — `CourseEditScreen`
- [기존] 코스명, 18홀 파(3/4/5), 지역·거리·시간, 평점, 난이도, 한줄평, 교통/클럽하우스/코스, 유튜브 링크 추가(검색 포함), 삭제
- 변경: 홀별 파를 전반/후반 2열 세그먼트 버튼으로 한 화면에. 상단에 "총 파 72", 각 열에 전반/후반 파 합계
- [신규-데이터] **평점·난이도 0.5 단위** (0.5~5.0), −/+ 버튼, 별 반 개·막대 반 칸 표시
  - 평점: 이미 `Double?` → UI만 변경
  - 난이도: 현재 `Int?` → `Double?`(REAL)로 바꾸는 **마이그레이션 필요**. 기존 값 보존(정수 → x.0)

## 3. 추천 구현 순서

1. 디자인 시스템 (테마, 색, 글꼴, 공통 컴포넌트: 카드, 스테퍼, 칩, 큰 CTA, 헤더)
2. 기존 기능 화면 교체: 홈 → 홀 기록 → 결과 → 홀 상세 → 코스 관리 → 코스 추가
3. 신규-UI: GIR/L-GIR 이름 변경, 결과 통계 6칸, 홀 결과 비율 막대, 홈 상단 요약, 18홀 진행 바·현재 스코어, 그린까지 거리 오버레이, 최근 N회 순위
4. 신규-데이터: 난이도 0.5 단위(마이그레이션), 스코어카드 공유
