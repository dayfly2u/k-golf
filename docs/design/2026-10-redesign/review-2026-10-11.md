# k-golf 리디자인 구현 리뷰 (시안 대비)

- 대상: `dayfly2u/k-golf` **master** `eb6fb35` (v0.9.9, 2026-10-11 08:14)
- 기준: 승인 시안 https://claude.ai/artifact/MzjUzRwBpQfZSmyLzSbhpY, `redesign-brief.md`, `mockups/*.dc.html`, 레포의 `docs/design/2026-10-redesign/redesign-spec.md`
- 방법: 코드와 시안 마크업을 화면별로 대조. **빌드·실행은 하지 않았음** (화면 모습은 코드에서 추론).

## 한 줄 요약

결과 화면과 디자인 시스템은 시안 그대로 잘 구현됐다. 홈과 홀 기록/홀 상세는 기능은 다 있지만 배치가 시안과 꽤 다르다. (난이도는 Kyle 결정으로 정수 1단위 유지.)

| 화면 | 충실도 | 비고 |
|---|---|---|
| 디자인 시스템 (색·글꼴·모서리·M3 테마) | 높음 | 토큰 전부 일치, 두 글꼴 번들, GolfTheme로 M3 보라색 제거 |
| 라운드 결과 | 높음 | 헤더·76sp 총타수·순위 뱃지·6칸 통계·100% 막대·스코어카드 모두 시안대로 |
| 코스 관리 | 높음 | 별+숫자 / 주황 난이도 칩, 하단 CTA, 벡터 아이콘 |
| 코스 추가·수정 | 중간 | 파 2열 세그먼트·총 파 OK. 별/막대 시각화 없음 (난이도 1단위는 의도) |
| 홀 기록 (라이브) | 중간 | 기능 다 있음. 헤더·스테퍼 카드·벌타 위치·하단 버튼이 시안과 다름 |
| 홀 상세 (리뷰) | 중간 | 같은 틀·수정 불가는 OK. 헤더 결과("7 · 더블") 없음 |
| 홈 | 낮음~중간 | 시간 형식, 접힌 카드 정보, 펼침 영역 구성이 시안과 다름 |

## 1. 꼭 고칠 것 (Kyle의 결정 또는 시안과 직접 어긋남)

1. ~~**난이도 0.5 단위 미구현.**~~ → 2026-10-11 Kyle 결정: 기존대로 정수 1단위 유지, 고치지 않음. `CourseEntity.difficulty`가 여전히 `Int?`이고 DB는 v19, 관련 마이그레이션 없음. 코스 추가 화면은 1단위 −/+ (`CourseEditScreen.kt:526` 주석 "스테이지 4 이후"). 스펙 5.1(스테이지 4) 전체가 아직 남아 있음. 평점 0.5 단위는 완료.
2. **홈 라운딩 시간 형식.** 현재 `2026-10-05 06:42~11:18 (4hr 36m)` (`RoundHistoryScreen.kt:122-137`). 시안/요청서는 `10.05 (일) 06:42~11:18 (4시간 36분)`. 결과 화면용 `formatRoundPeriod`(`RoundSummaryParts.kt`)가 이미 정확한 형식이라 그걸 재사용하면 됨.
3. **홈이 "깔끔한 리스트"가 아님.** 접힌 카드에 그린피·동반자 줄이 항상 보임(`RoundHistoryScreen.kt` infoLine). 시안은 펼칠 때만 표시.
4. **홈 펼침 영역 구성이 시안과 다름.**
   - 시안: 베이지 인용 박스에 리뷰 → 4칸 통계 타일(GIR / 퍼팅 / 드라이버 / 벌타) → "상세 결과 보기 ›"
   - 구현: `L-GIR 6/18 (33%) / GIR 4/18 (22%)` 텍스트 줄(검정/빨강, `Color.Black`/`Color.Red` 하드코딩 — `GirSummaryLines.kt`), 통계 텍스트 줄, `리뷰: ...` 접두 텍스트
   - 리뷰가 없을 때 시안은 "리뷰 남기기" 링크인데, 구현은 안내 문장만 있음(탭 불가)
   - `StatGrid.kt` 주석엔 "홈 펼침은 4칸"이라고 돼 있는데 실제 홈에서는 안 씀
5. **헤더 우측 숫자 누락.**
   - 홀 상세: 헤더 우측 "이 홀 7 · 더블"이 없음(요청서 2.4에 명시)
   - 홀 기록: "현재 스코어 +5"가 헤더 우측 큰 숫자가 아니라 진행바 아래 작은 회색 글씨

## 2. 시안과 다른 모양 (기능 영향 없음)

**홈**
- 평균 스코어/베스트/평균 퍼팅 3칸이 녹색 헤더 안 반투명 타일이 아니라, 리스트 첫 줄의 흰 카드로 들어가 있음
- 헤더 로고 아이콘 없음. "코스 관리"가 테두리 pill + 핀 아이콘이 아니라 평범한 텍스트 버튼
- "최근 라운드 · 총 N회" 소제목 없음
- 스코어 배지가 64dp 정사각 블록(숫자 + 파 대비) 대신 작은 숫자 배경, 파 대비는 배지 밖
- CTA 문구 "새 라운딩 시작!" (시안 "새 라운드 시작" + 아이콘). 요청서는 "새 라운딩 시작!"이라 어느 쪽이든 OK

**홀 기록 (라이브)**
- 헤더 "HOLE 7" → "7홀"
- 스테퍼 3행이 흰 둥근 카드로 묶여 있지 않음
- 벌타 버튼 줄이 "그린까지"와 "숏게임" 행 사이에 끼어 있음. 시안은 스테퍼 카드 아래 "벌타" 라벨과 함께 한 줄
- 라벨 "숏게임" → "숏어프로치"
- "위치 조정"이 지도 우하단 흰 pill 오버레이가 아니라 지도 위쪽 텍스트 버튼
- 그린 거리가 시안의 어두운 박스 + 큰 숫자("그린 중앙까지 / 142m")가 아니라 작은 녹색 pill "그린까지 약 142m"
- 하단 버튼이 기본 크기. 시안은 이전 홀 110dp, 다음 홀이 나머지 폭 전체, 높이 56dp이고 "이 홀 5타 · 보기"가 다음 홀 버튼 **안**에 있음(구현은 버튼 아래)

**홀 상세**
- 벌타 칩이 "그린까지" 행 바로 아래에 끼어 있음. 시안은 별도 흰 카드 "벌타 | OB 0 | 해저드 0"
- 지도 위 "직선 거리 · 고저차 미반영" 안내 없음
- 하단 버튼이 "3번 홀 / 5번 홀"이 아니라 "이전 홀 / 다음 홀"

**코스 추가·수정**
- 평점 별 5개(반 개 채움), 난이도 막대 5칸(반 칸 채움) 시각화가 없고 "평점: 4.5" 텍스트 + −/+만 있음
- −/+ 버튼이 40dp라 최소 터치 영역 44dp 미만

**코스 관리**
- 펼침의 유튜브 링크가 썸네일 없이 "▶ 제목" 텍스트 (`VideoThumbnail.kt`는 있는데 여기선 안 씀). 사소함

## 3. 코드 보다가 눈에 띈 것 (추론, 실행 확인 안 함)

- **그린까지 거리가 걸어가도 안 바뀔 수 있음.** `currentLocation`은 홀이 바뀔 때와 "위치 조정"을 누를 때만 갱신됨(`RoundPlayScreen.kt` `LaunchedEffect(hasLocationPermission, currentHoleNumber, online)`). 페어웨이를 걸어가는 동안 숫자가 그대로일 가능성이 큼. 시안 의도(지금 위치에서 그린까지)와 다름.
- **80타 미만은 홈 배지 색이 없음.** `strokeScoreTier`가 80 미만이면 null을 돌려줘서, 가장 좋은 기록이 가장 밋밋하게 보임.

## 4. 시안과 다르지만 의도된 변경 (문제 아님)

- 스코어 색: 시안의 흰/연파랑/진파랑 대신 버디 금색 · 파 진녹 · 보기 연초록 · 더블 연빨강 · 트리플+ 진빨강 5구간 (v0.9.1~v0.9.5에서 Kyle이 선택)
- 홀 상세 실수 항목 연빨강 하이라이트 (v0.9.7)
- 결과 화면 리뷰 카드 (v0.9.8), 삭제 버튼 유지
- 스코어카드 공유 버튼 없음: 스펙에서 범위 밖으로 결정
- 홈 하단 백업/복원, 라이브 벌타 "탭해서 취소" 칩: 기존 기능 유지 목적

## 5. 잘된 점

- 토큰 값이 요청서 표와 100% 일치하고, 화면별 하드코딩 색을 `GolfTokens`로 모음
- 결과 화면은 거의 픽셀 수준으로 시안을 따름 (34dp 라벨 칸, 28dp 셀, 22dp 막대, 퍼센트·범례)
- GIR/L-GIR 표시명 교체를 의미 변경 없이 라벨만 바꾸고 주석으로 남김
- 18홀 진행바 라이브/리뷰 두 모드, "현재 스코어"에서 현재 홀 제외 처리 정확
- 최근 5회 순위, 홈 요약 통계에 단위 테스트 있음
